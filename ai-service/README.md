# AI/NLP Microservice (Python + FastAPI)

This is an internal microservice that handles web text extraction, tokenization, lemmatization, summarization, sentiment classification, keyword extraction, entity recognition, and local RAG indexes.

---

## 1. Prerequisites
- **Python**: Version 3.10 or 3.11 recommended.
- **Hardware Acceleration**: Automatically detects and uses **MPS (Apple Silicon M1/M2/M3)**, **CUDA (NVIDIA GPUs)**, or falls back to **CPU**.

---

## 2. Installation and Setup

1. Navigate to the `ai-service/` directory:
   ```bash
   cd ai-service
   ```

2. Create a Python Virtual Environment:
   ```bash
   python3 -m venv venv
   ```

3. Activate the Virtual Environment:
   - **macOS / Linux**:
     ```bash
     source venv/bin/activate
     ```
   - **Windows**:
     ```cmd
     venv\Scripts\activate
     ```

4. Install the required dependencies:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Download the spaCy English language model:
   ```bash
   python -m spacy download en_core_web_sm
   ```

6. Create your `.env` configuration file (copy from `.env.example` if needed):
   ```bash
   cp .env.example .env
   ```

7. Configure your `.env` file:
   - To use Gemini Q&A: Add your Google AI Studio API key to `LLM_API_KEY`.
   - Set `LLM_PROVIDER=gemini` (or `openai` if preferred).
   - Set `LLM_MODEL=gemini-1.5-flash` (or your chosen model name).

---

## 3. Running the Microservice

Start the internal Uvicorn server:
```bash
uvicorn app.main:app --reload --port 8000
```
The service will be active at `http://127.0.0.1:8000`.

---

## 4. Models and Pipelines

- **NLP Preprocessing**: normalizes unicode characters, simplifies whitespaces, and uses a lazy-loaded `spaCy` (`en_core_web_sm`) pipeline to perform token lemmatization and filter stopwords/punctuation.
- **Summarization**: loads Hugging Face `facebook/bart-large-cnn`. Long articles exceeding the token limit are split into sentence-aware blocks, summarized, and combined.
- **Sentiment Analysis**: uses `cardiffnlp/twitter-roberta-base-sentiment-latest` to classify text into `POSITIVE`, `NEUTRAL`, or `NEGATIVE`. Probability scores of long texts are chunk-averaged.
- **Keyword Extraction**: utilizes `KeyBERT` with the `all-MiniLM-L6-v2` Sentence Transformer. MMR (Maximal Marginal Relevance) is applied to remove overlapping keywords.
- **Named Entity Recognition**: uses `spaCy` to extract PERSON, ORG, GPE, LOC, DATE, MONEY, EVENT, and PRODUCT.
- **RAG Engine**: Chunks text and embeds them using the shared SentenceTransformer. Vectors are indexed using local `FAISS` indexes under the vector store path.

## 5. API Endpoints

### Health Check
- **GET** `/health`
  - Returns: `{"status": "AI service is running"}`

### Article Text Extraction
- **POST** `/api/extract-article`
  - Body: `{"url": "https://..."}`
  - Returns: `{"title": "...", "article_text": "..."}`

### Article NLP Analysis Pipeline
- **POST** `/api/analyze`
  - Body: `{"article_text": "...", "summary_length": "medium"}` (Values: `short`, `medium`, `detailed`)
  - Returns: Summaries, sentiment label & scores, top 10 keywords, entities, word counts, and compression ratio.

### Context-Grounded Ask (RAG)
- **POST** `/api/ask`
  - Body: `{"article_id": "...", "article_text": "...", "question": "..."}`
  - Returns: The final answer generated by Gemini/OpenAI (strictly sourced from contexts) and the matching reference source chunks.
